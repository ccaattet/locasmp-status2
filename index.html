STEP 01

Welcome to LOCA SMP

Getting started is easy. Connect to the server and begin your survival adventure.

  1. Open Minecraft Java Edition.
  2. Go to Multiplayer, then Add Server.
  3. Enter locasmp.top as the server address.
  4. Join, explore and start collecting resources.

GOOD TO KNOW

Frequently asked questions.

What is the LOCA SMP server IP?

Use locasmp.top in the Multiplayer server address field in Minecraft Java Edition.

How do I start making money?

Start by collecting resources, then check the in-game shop and available selling options. Your balance uses the server's configured economy.

Can I play with friends?

Yes, provided your friends can connect to the server and meet its version and access requirements. Share the server address with them.

Why does the server show as offline?

The status provider may be unable to reach the server, the server may be offline, or status queries may be restricted. The result is not a definitive server-side diagnostic.

Can I join from Bedrock Edition?

Bedrock access depends on your current Geyser and proxy configuration. Confirm the correct Bedrock address and UDP port with the server administrator before connecting.
